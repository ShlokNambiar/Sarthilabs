# Sarthi Labs

Static site, no build step. Host on GitHub Pages (Settings → Pages → deploy from `main` / root).

- `index.html` — landing page
- `urban-sanction-desk.dc.html` — live case form
- `urban-sanction-journey.dc.html` — step-by-step walkthrough
- `sarthi-reach.dc.html` — Sarthi Reach
- `Sarthi Labs Logo.dc.html`, `logo/sarthi-mark.svg` — logo
- `_ds/` — design system, `support.js` — page runtime, `GhostFibers.jsx` — hero background
- `CNAME` — custom domain (sarthilabs.in)

Serve over HTTP (not file://). Fonts load from Google Fonts.
